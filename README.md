# Site Collaboratif

## Description
Site web collaboratif créé pour maîtriser Git et GitHub dans le cadre de la formation Kadea Academy.

## Objectifs atteints
- Initialisation et configuration du projet Git
- Gestion des branches (develop, feat/contact, feature/footer)
- Résolution de conflit de fusion
- Utilisation de .gitignore
- Commandes avancées (git restore, git revert, git stash)
- Collaboration sur GitHub (Push, Pull Request)

## Technologies
- HTML5 / CSS3
- Git / GitHub
